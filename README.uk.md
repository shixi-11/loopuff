## Поточний код

Репозиторій містить невеликий навчальний інтерпретатор чисел, додавання, зв’язування імен і виведення. Він працює локально без сервера, зовнішніх моделей і сторонніх пакетів. Інтерфейс гри та навчальні матеріали перебувають у розробці. Це не повний компілятор Tolang і не TVM.
