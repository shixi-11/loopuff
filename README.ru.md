## Текущий код

В репозитории находится небольшой учебный интерпретатор чисел, сложения, связывания имён и вывода. Он работает локально без сервера, внешних моделей и сторонних пакетов. Интерфейс игры и учебные материалы находятся в разработке. Это не полный компилятор Tolang и не TVM.

## Разработка

```sh
npm test
npm run build
npm run dev
```

## Языковые правила

Интерфейс, уроки, вопросы, подсказки и ошибки отображаются на выбранном языке. Китайские названия — 环灵 и 環靈; на остальных языках используется Loopuff. Идентификаторы и символы кода не переводятся. Арабский текст идёт справа налево, код — слева направо.
