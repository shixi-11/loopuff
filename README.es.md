Aprende programación y Tolang jugando.

Lee código, predice el resultado, modifica el programa y resuelve problemas nuevos sin una plantilla.

## Código actual

El repositorio contiene un pequeño intérprete educativo para números, sumas, asignación de nombres y salida. Funciona localmente sin servidor, modelos externos ni paquetes adicionales. La interfaz del juego y las lecciones están en desarrollo. No es el compilador completo de Tolang ni la TVM.

## Desarrollo

```sh
npm test
npm run build
npm run dev
```

## Normas de idioma

La interfaz, las lecciones, las preguntas, las pistas y los errores usan el idioma elegido. Los nombres chinos son 环灵 y 環靈; los demás idiomas usan Loopuff. Los identificadores y símbolos del código no se traducen. El texto árabe va de derecha a izquierda; el código, de izquierda a derecha.
