# First-time reader orientation

The guide and arcade previously assumed readers could connect terms, code and game signals. The first minute must instead provide a purpose, one available action, an observable result, and a clear next action. This change addresses the guide, its concept map and the vault puzzle together. Existing lesson IDs, source examples, grading, saves, approved artwork and browser scale remain unchanged.

- Guide: explain what programming, code and Tolang refer to before the experiment. Keep the selected draft; place other concepts behind an optional disclosure. Describe each concept by its use, explain the original executable example separately, and put Run before the optional prediction. An actually executed result changes the first-step prompt and offers the next idea without recording completion. Editing withdraws that result and next suggestion. Existing comparison, diagnostic, map and independent-work entries remain available.
- Map: give first-time readers an explicit introduction entry. Put the selected concept's ordinary meaning, purpose and learning actions before the full graph. Add a plain description to every existing node; the graph remains freely selectable and its original dependencies remain authoritative.
- Vault: show the actual target numbers and order, explain that code supplies numbers to the lock, and provide an explicit editor-focus action. The original starter gets a concrete hint using this run's clues. A previously edited draft gets a general comparison instruction rather than an incorrect instruction to replace a nonexistent zero. Later mechanisms explain names and ordered outputs. The existing runner, successes, stamps, recovery and three stages are unchanged.

Scope of evidence: focused prompt, clue and guide-UI checks; required full frontend tests and build; real guide execution/editing, vault mismatch/correction and progression, map selection, language/reload, narrow/RTL layout; independent read-only review; Git sync and deployment/asset/entry verification. Tests and developer playthroughs do not establish novice understanding.

Verification: 248 frontend checks and the static build pass. Two independent read-only reviews found the same stale vault hint and hidden guide focus issues. Both failed in event-level regression checks before the fix and pass afterward; the second review confirmed both closed. Guide source 7.log() and 9.log() produced their respective actual outputs, and the new next-idea action focused the visible editor. The vault's initial 5 output failed its real target of 9; changing the starter to calculate 5 + 4 opened the lock, and the next mechanism was exercised. Selecting a map node now focuses its explanation heading below the real sticky header. At 390×640 all 11 locales across the three pages have no page overflow; exact guide/vault editors preserve source across language changes and keep LTR direction. These layout measurements do not constitute a human translation review.

The user's actual preview width also exposed a tablet gap: the observation scene preceded the editor between 560 and 900 pixels. The beginner view now puts the editor first throughout that range, and its first experiment has an explicit entry button that focuses and reveals the existing editor without changing any model data. In the actual preview, the focused editor starts below the sticky header and its Run action is visible. The user draft 9.log() remains intact; browser zoom and page scale are both 1.

Distinct causal reference experiments are implemented for functions and joined messages; see causal-experiments.md for their execution, isolation and verification boundaries. They expose real arguments/calculation/return/output and one-message waiting versus both-message execution, and edits invalidate their observations. They are labelled reference examples and do not replace the learner's program or award mastery. Final small-change and narrow/RTL browser verification is still open because local browser control is disabled. Further transfer from these reference models to independent programs, and actual novice comprehension, remain unproven.
