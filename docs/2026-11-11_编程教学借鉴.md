# 其他语言学习网站对环灵的启发

2026-11-11 核查。资料来自官方页面、文档及公开源码；没有安装、登录或完整试玩这些产品。下列适配是环灵的设计判断，不能据此宣称教学效果已得到验证。本次只借鉴方法，没有引入第三方代码、课程或素材。

## 做了什么，怎样构建

| 参考 | 官方说明与结构 | 环灵的应用 |
| --- | --- | --- |
| [Python Tutor](https://pythontutor.com/) | 逐步执行并显示变量、对象、数据结构和调用栈，帮助理解代码实际发生的事 | 把真实输出位置与角色动作连起来。先观察一次动作，再修改程序并比较 |
| [Exercism](https://exercism.org/docs/building/tracks/concept-exercises) | 概念练习有介绍、任务、起始代码、提示、测试、范例及概念元数据；[各语言运行器](https://exercism.org/docs/building/tooling/test-runners)负责执行提交 | 课程目标、提示和测试场景与运行器分开；区分讲解、试写、独立检验，保留不同正确解法 |
| [Rustlings](https://rustlings.rust-lang.org/usage/) | 按主题练习，修改后重跑，遇到困难可以请求提示；[首题](https://github.com/rust-lang/rustlings/blob/main/exercises/00_intro/intro1.rs)从可运行代码开始 | 让新手先运行一条能理解的命令，再逐步改错；提示由学习者主动展开 |
| [CodeCombat / Aether](https://github.com/codecombat/aether) | Aether提供代码分析、执行、单步及可视化能力，面向它所支持的语言 | 游戏画面使用真实执行结果；保留环灵自己的Tolang入门运行器与物理规则，不将JavaScript引擎当作Tolang实现 |
| [Codemm](https://github.com/iignaite/Codemm) | 接受练习前检查参考解通过、起始代码失败，并用测试拒绝准备好的错误变体；练习与正式检查分开 | 在构建前验题，确保当前样例能识别指定典型错误。有限错误集合只证明这些检查，不能保证题意完整或学习者已掌握 |

## 本轮落地

追逐试写从`1.log()`开始。它能运行并产生稳步动作，但尚不能满足条件策略；玩家再修改同一程序。原有试写内容在页面重挂载时保留，不替换现有策略草稿。提示分为输入与动作、条件与临界值、局部写法三层；成功后收起，可以再打开。

同一程序每次执行于九组输入：当前快照、近障碍、通畅高体力、通畅低体力、距离4且体力35、距离4且体力36、距离1、障碍优先、近障碍低体力。检查实际输出，不匹配参考文本。构建前校验参考解，并拒绝十一种指定错误程序；测试通过删除关键场景验证这套验题检查确实能失败。

选择情境后显示输入、要求、实际行动及产生输出的源代码片段。独立短街重演该行动，复用现有角色素材与真实移动、起跳、体力和碰撞规则。每步0.2秒，最长1.2秒，首次碰撞或跨越后停止。它仅展示一次行动，不能据此宣称整份策略已在真实追逐中获胜。

预演、提示和检查不推进主追逐、不增加有效时间、不改成绩、已部署策略或保存格式。采用仍经原有检查、覆盖确认和保存，再由玩家明确部署。保持正常字号、海军蓝与冷白配色、原有美术和11语；桌面代码与反馈并排，窄屏纵向排列。

## 后续研究范围

跨任务自适应课程、完整多语言后端、自动出题Agent不在本轮实现内。当前入门解释器的支持范围不变。新增任务时继续核对目标、不同正确解法、指定反例和真实运行；零基础能否独立理解与迁移，仍需实际学习者体验，不能由测试总数代替。
