# 像素深空与可编程掌机

2026-11-12，用户选定独行宇航员面对巨型圆环的像素深空方向。首页主场景保持原生1672×941像素，原始PNG在`美术资产/首页/深空圆环.png`；运行用WebP为同尺寸无损编码。原图另按要求复制到内容运营的Loopuff宣传图目录。标志为32格矢量构图，512像素PNG是从同一矩形几何直接渲染，正式SVG与PNG同步到视觉设计的Logo目录。

首页把场景与主要入口留在首屏，数值实验和掌机入口移到下方。掌机放在现有游乐场内，保留原有课程、存档和其他游戏。新游戏的当前局保留在页面会话中；切换语言或离开会暂停，刷新开始新的会话。

## 游戏与代码

三个确定性纯引擎分别处理落块消行、基地坦克防卫和纵向射击。手动按键与Tolang控制共用真实引擎。控制台调用掌机提供的Tolang同步函数，生成经过检查的指令；整批运行成功且指令合法后，按120毫秒间隔依次交给游戏，不把重复动作去重。`choose(1..3)`准备新局，`start()`开始或继续，`pause()`暂停，`finish()`提前结束；结束后再开始为新一局。

控制台只编排操作，不读取会随执行变化的游戏局面。自动策略每250毫秒获得一次明确的整数输入快照，重新运行后持续操控当前时间段。输入说明列在策略面板中，落块坐标与坦克格坐标、飞机像素坐标分别解释。策略不允许选择、开始或结束；运行失败时停止策略并暂停。解析和计算复用现有受限学习运行器，没有JavaScript eval或任意宿主调用。掌机函数不宣称属于Tolang标准库。

隐藏页面、窗口失焦或离页都会停止待执行队列和旧动作；恢复需要主动开始。键盘及触屏均能停止自动策略并接管。计时仅在可见且运行时推进，过长帧差有上限。

## 来源与语言

实际复用Jake Gordon Javascript Tetris的七种旋转位掩码，原MIT许可在`public/licenses/javascript-tetris.txt`，NOTICE标明范围。七袋、锁延迟、踢墙、画面和其他两个游戏为本项目实现；没有接入ROM或复制旧游戏贴图。Battle City与Kontra作为架构调研线索，没有引入其代码或依赖。

语言集合与顺序依据shixilin.com：简体、繁体、英语、德语、西语、法语、越语、俄语、乌克兰语、阿语、日语、韩语。补齐完整法语目录，并让服务端存档接受fr；其余旧语言内容保留。新增掌机内容提供全部12种语言。

## 检查边界

纯引擎、跨模块Tolang命令、输入接管与中断使用真实生产模块验证；DOM与RAF替身只提供浏览器表面。浏览器另核对实际首页、选游戏、开始、操控、暂停、结束及不同语言的布局。这些检查证明实现和对应操作成立，不是新手学习效果或用户对全部页面的最终认可。

## 街区与货场

街区设上下两排商店、横向道路与纵向巷道；角色沿可通行区域巡游，点击地面寻路，键盘接管后停止自动行走。各商店有独立颜色与年代标识。三个经典游戏从店门进入同一掌机，学习入口与现有长街追缉、货场调度、银行协作课程保留；保险库退出主入口但旧路由与存档保留。

货场调度以起重机和集装箱表现真实程序输出。吊装依次对应每项实际输出，空输出不虚构成功，错误泊位与无效值各自可见；减少动态时展示同一结果的静态位置。追逐名称按用户确认定为长街追缉。
