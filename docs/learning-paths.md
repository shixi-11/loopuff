# 两条学习路线

2026-11-11：两条路线已接入现有“编程入门”页，使用原有运行器、课程、诊断及项目。首页、游乐场和原有练习入口保留。

- 第一次学编程：`/zh/guide/start/`。六步依次为运行、改数、修错、计算、起名字、根据路障判断。每步有具体目标、可编辑程序、真实结果、产生结果的源码、可选提示及解释。通过后才开放下一步，也能主动回看任意一步。随后按四段航程进入原有13项课程。
- 已有基础，继续进阶：`/zh/guide/advance/`。从九类多输入诊断定位需补的概念，再进入四项组合任务。已有有效提交会重新执行核验；全部诊断通过后推荐首个未完成项目。可进入语言对照、补学和独立编程，再返回原路线。

两类页面均提供11种语言，支持独立站与`/games/loopuff`路径。`step`定位入门步骤；受限的`path=start|advance`记录学习来源，保留到课程、结果、诊断、对照及调度项目，支持直接打开链接后返回。

## 检查与存档

六步练习通过实际解释执行检查输出、结束状态及必要概念。计算和名字练习要求相应概念参与结果数据，不能把计算放在无关条件里再输出固定答案。条件练习使用六个输入，覆盖小于、等于和大于边界。不同正确写法可通过。

仍使用现有存档版本及字符串字典`guideWork`。原有八项入门草稿与选择不变；新步骤使用`start-<id>`保存草稿、`start-<id>-checked`保存实际运行过的源码。编辑即撤回本步验证，恢复时只有源码一致且重新执行通过才显示已验证。保存失败或尚未完成时不进入下一步。

备份合并把每步草稿与已检查源码作为一个原子选择，保留显式空稿。重置写入起始源码，不能与旧完成记录拼接而自动恢复完成；冲突页显示对应路线及步骤名称。

`scripts/verify-start-exercises.mjs`在构建前验证参考程序、起始程序、有意错误及固定答案绕过。测试覆盖存档往返与冲突、运行与改写、等待、保存失败、语言切换时的异步保存、真实推荐、两种部署路径和全部本地化入口。页面检查还包括六步完整操作、错误修复、替代正确解、刷新续学、进阶推荐和学习返回链接。

这些记录只证明相应程序在公开案例中通过。当前课程使用受限学习运行器；完整Tolang工具链、系统工程课程及真实新手理解效果仍需后续实现和验证。
