# 课程执行场景

十二项课程使用可回放的执行场景；`leap` 继续使用原跳跃场景，不重复消费输出。课程编号、原例程、任务判定、成绩与既有存档字段保持不变。独立编程页以课程名称为标题，任务目的在工作区上方，观察场景与编辑器并排；手机按单列组织，改写阶段先展示目的与场景，再展示填空和源码。

## 观察的事实

`run(source, {trace:true})` 只增加可选的关键动作记录。默认调用没有新增返回字段；输出、源码区间、概念贡献、函数完成调用、模型步数、等待结果和错误保持原有含义。记录不增加解释器的调度让出点或执行步数。

场景只回放实际记录，不重新解释源码或根据最终输出编造中间步骤。记录涵盖通道、名字、赋值、列表项、计算、条件、同步函数及回复、发送、等待、接收和输出。消息在真正入队时获得记录用标识，联合接收成功消费全部所需消息后才记录；重复通道需求与竞争接收保留各自身份。等待只在实际无法消费时出现，不能为了演示而补一段等待动画。

通道别名来自每个动作当时的环境快照。复制到函数或并行分支中的同一绑定标识不被当作一份全局可变存储；局部重绑不会改变另一环境的标签。函数体中的数值按调用实例展示，避免把接收变量与同名函数参数混成一个全局盒子。

这些是学习运行器中的一次执行记录，不代表所有合法并发顺序、原生编译器指令、TVM成本或真实时间。当前语言依据固定在官方提交 `c4c38934a9d500c8acbda3735633d69e339eece1`；本次没有引入新的语言语法，也没有公开或外发上游私有源码。

## 教学阶段与保存

- 简报显示未执行场景，不渲染目标答案，也不能提前运行。预测阶段保留原选择过程。
- 观察和解释使用原课程例程。改写使用玩家当前实际填入值后的完整程序；独立观察使用当前草稿，正式提交沿用原测评。
- 结果页只使用与当前草稿匹配的已提交源码。场景中的“输出与目标一致”只描述输出；写死常数仍不能冒充需要消息、函数或分支贡献的课程任务。
- 回放、跳步、暂停与重看不重新运行程序、不增加成绩或完成次数。编辑立即清除轨迹，语言切换、离页、后台与减少动态效果会停止回放。
- 执行记录、消息标识、游标和播放状态全部暂存于场景控制器，不进入课程或账号存档。文件和账号备份使用现行v3六域契约，并保留旧四域、五域文件的兼容读取。

## 有限记录与错误

回放最多记录512条关键动作；每个列表值以有省略号的有限预览显示，避免共享嵌套列表膨胀标签。真实输出仍保留运行器本来的打印格式与限制。

截断只限制画面，不提前停止程序。回放的前缀、完整运行输出和最终错误／等待分别显示；截断时不把最终错误位置高亮成第512条记录的现场。空列表、正常无输出、未满足接收与运行错误仍是不同结果。语法错误没有虚构执行轨迹，运行中错误只显示已经发生的事件与实际输出。
