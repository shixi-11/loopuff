# 网站体验修订

目标：让首次访问者知道从哪里开始、先做什么、结果怎样产生；已有基础者和回访者能直接继续实际任务。保留深蓝与冷白视觉、现有飞机及角色、课程ID、草稿、成绩和游戏机制。基线为`946745e`，主笔为当前Codex会话。

## 本轮完成条件与改动

- 首页由单屏宣传改为“动手运行→选择路线→游戏用途→学习方法→概念帮助”。桌面采用说明与真实小实验并排，手机按阅读顺序重排；未通过全局缩放改变比例。
- 首页小实验调用现有运行器执行0—99整数的`.log()`，编辑后撤回旧结果。它只修改同会话的预览状态，不写课程成绩，也不替换任何草稿。
- 首次主按钮进入六步路线；有效课程记录继续通过原`lessonWork/enterLesson`恢复。六步完成后，就近提供下一个未完成课程的标题和入口；等待保存和保存失败时不开放这个交接入口。
- 正确输出但缺少指定方法，与输出错误分别反馈。独立任务在普通点击、复制链接、新标签和刷新时使用相同的`practice=independent`目的地；改写仍为`practice=rewrite`。
- 概念地图的零基础起点直接进入六步路线。进阶页把重复九次的语言对照入口集中到主题列表之前。
- 因果实验中的“你的Tolang代码”链接使用完整页面路径和片段，避免`base`使它跳到首页。已检查`src`与`public`中的同类裸片段链接，本次仅发现这一处。
- 游戏厅追逐卡显示连续追逐的实际角色、有效用时与续玩入口；跳跃卡不再把“继续航程”同时当作记录和按钮显示。
- 连续追逐显示真实当前角色与强度，首次开始采用所选设置后同步刷新。设置标签明确属于新局；原首次选角、新局确认、暂停和保存机制保留。
- 银行潜入把现有1—6行动编号放到编辑器之前，完整规则和输入仍可展开查看。未改变编号含义或策略运行机制。
- 所有新增说明支持原有11种语言；阿拉伯语界面RTL、代码LTR。

## 证据与复核

构建：`npm run build`；测试：`npm test`；改动检查：`git diff --check`。本机无独立lint任务，差异检查只覆盖格式，不冒充静态语义检查。Node不在PATH时使用`A:/vibe coding/_runtime/node/node.exe`执行相应脚本。

缺方法反馈的变异检查、完成入口保存失败检查、根路径`base`下的编辑器链接检查，均证明修复前失败、修复后通过。首页实验验证真实执行、编辑失效、同会话换语言保留；入口测试保护已有草稿与实际续学。

独立内容审查的五项问题均已修复；游戏审查提出的原首次选角问题，经重新读`resume()`确认原行为正确，未按错误判断删去。随后发现的当前角色显示回归已修复并由第二位审查者关闭；完成入口未等待保存的问题也已修复并关闭。

页面检查包括：首次无进度进入六步第一步并运行、已有进度续学、正确输出缺加法反馈、六步完成的命名课程入口、复制独立链接并刷新、地图起点、追逐首次选择小偷后开始与暂停、游戏厅对应续玩记录、潜入可见行动表。另走查编程入门、两条路线、语言对照、概念地图、诊断、游戏厅、保险库、调度、潜入、账号、备份及课程/无结果状态；手机首页检查11种语言，代码输入和结果保留，无页面横向溢出。

截图、失败与通过日志、静态字号审查及部署核对保存在`output/website-audit/`。字号审查只剩九个实际字号的P3提示；显示标题、章节标题、正文、辅助文字、代码和数字按角色分配，已通过实际桌面/手机检查，不把静态提示数量当作审美成绩。

## 边界

本轮未改变学习运行器语义、追逐胜负/十分钟有效计时、上游源码或存档格式。已按现役ALUX大师核对来源；`.log()`仍采用已有支持，未加入未知语法。私有来源记录留在本机，未引入第三方源码或素材。

真实新手试学、跨任务学习效果与完整Tolang工具链课程仍不由这些界面检查证明；完整课程规划见`experience-direction.md`和`roadmap.md`。本轮验收针对上述具体改动，不能据此断言网站没有其他问题。
