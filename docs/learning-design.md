# 从零开始与 Tolang 学习编排

本次范围：给现有十一项真实练习补上初学者理解所需的解释与示例，并把进阶 Tolang 示例放到更容易找到的位置。保留已经确认的视觉、街区、游戏、题目 ID、评分条件与历史草稿。

## 参考资料与实际阅读范围

- 《零基础入门学习 Python：微课视频版》，小甲鱼（李佳宇）：用户云盘中的上卷。局部核对 PDF 第 3–18 页的前言、目录，以及第 26–34 页首次运行、失败尝试、算术与第一个小游戏开头；没有声称读完整书。吸收成功示例之后只改变一个因素、把错误作为正常练习的安排。不复制书中的叙述、图像或习题。
- 《Scala 编程》第三版，Martin Odersky、Lex Spoon、Bill Venners：用户云盘中的英文版。局部核对目录和第二章开头，主控另核对 PDF 第 33–34 页：交互输入、实际回显、前一值参与后续计算。快速上手与完整解释分开，适合已有基础者，但不把“先略过细节”变成零基础教学的默认。
- 用户云盘的《Tou 编程语言介绍》是语言愿景材料，与 Tolang 名称和语义不能混用；不作为 Tolang 当前语法或示例的依据。
- 本地早期学习原型的 README、七项基础概念与前三课：吸收单目标、语义分片、预测、执行、单变量变式的结构，不恢复其旧视觉。
- [赫尔辛基大学 Python MOOC 首课](https://programming-26.mooc.fi/part-1/1-getting-started/)：核对首个指令、实际输出、缺少符号的错误和多条指令。借鉴每次只增加一个新要求的节奏。
- [Think Python 第一章](https://greenteapress.com/thinkpython/html/thinkpython002.html)：核对程序、输入、输出、计算、条件、重复及错误分类。基础定义要与当下可观察的例子联系。
- [Python 官方教程](https://docs.python.org/3/tutorial/)明确面向已有编程基础而刚接触 Python 的读者；不直接用作本站零基础课程顺序。
- [Rust Book 的 Hello World](https://doc.rust-lang.org/book/ch01-02-hello-world.html)：核对完整示例、实际运行、再逐部分解释，以及编译和执行的区分。本站不要求新手先配置命令行。
- ALUX Programming 本地手册的目录与“Why meaning comes first”：属于方法参考，不是零基础 Tolang 教材。官方实现来源在本轮核对并固定为 `c638bdb4d30240439a9e53051fb1253b64d9cb67`；语言事实由主控本地核对，私有实现不随本项目公开。

## 已落地的学习顺序

1. 首课先解释代码、运行、输出，说明在哪里写、按哪个按钮、到哪里看结果。
2. 看懂、运行、修错：先建立指令与结果的联系。
3. 计算、命名、条件：让数据真正参与结果，并检查分数 9 与 10 两侧的边界。
4. 掌机操作：选择、开始、移动、开火、循环、结束，最后让同一策略处理不同位置。
5. 每步先有一个独立运行的小示例，再给不同的练习目标。示例从已有解释器和游戏状态产生结果，不能写入草稿、完成记录或奖励。
6. 预测选填、不计分；执行后显示真实结果和对照提示。判断掌握仍以学生自己的代码、真实输入和既有检查为准。
7. 进阶页默认展示四个 Tolang 完整示例：函数、回复、消息、联合接收；已有的多输入诊断与组合任务继续保留。

`choose/start/right/fire/finish` 是本站掌机提供的调用，不当作 Tolang 标准库。学习运行器只实现本站公布的教学范围，不当作完整 Tolang 编译器或 TVM。游戏帧与执行结果来自实际运行，不使用预设成功输出。

## 检查边界

针对示例与学生草稿隔离、预测不授予进度、语言完整性、真实运行、修错、输入边界、草稿重载与进阶入口进行测试。电脑 1440、平板 768、手机 390 像素分别检查；其他十一种语言检查首课运行和页面横向溢出，阿拉伯语另核对实际画面。浏览器模拟检查不等于真实学生已经掌握，后续教学效果仍需要实际学习反馈。

下载的参考书仅留本地研究目录，不进入 Git、网站资源或公开交付。
