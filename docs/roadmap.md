# 环灵玩法与学习路线

目标：让零基础玩家通过观察、编写程序、验证结果和调整方案，逐步能独立用 Tolang 解决问题。打字速度、游戏通关与编程能力分别看待。

小主人2026-11-03在实机页面上的追加要求见[体验方向](experience-direction.md)：学习任务融入游乐场，取消独立“关卡”主导航；零基础引导与已有基础者的诊断／掌握路径同时完善；增加语言对照与概念地图子页面；追逐改为至少十分钟有效行动后结算整场胜负的连续体验，途中失误改变后续局势。原短实验仅作可选代码练习，保留旧档和调试。下文现有短关卡记录不构成新连续体验已经完成。

2026-11-03 已设立持续完善目标，覆盖编程零基础、Tolang 入门与进阶，以及与课程相互支持的游戏性。[同类产品的复用研究与采用顺序](programming-game-references.md)记录了源码和内容的许可边界。已实现13项课程、交互信号台与语言对照、手动备份和账号存档、连续追逐与原短实验，以及九类多输入诊断。十二项课程新增可观察的执行场景，原跳跃课单独保留；按表现撤除支架、更深入的任务世界和迁移反馈仍需推进。现有页面风格、警察／小偷跳路障、入口、草稿和旧存档保留。

## 当前可玩内容

- 四段入门航程：输出、加法、名字与输出驱动的飞行，含预测、解释、修改和独立任务。
- 六项Tolang实练：比较、分支、for、while、同步函数与函数回复。三项消息协作：发送接收、联合接收、综合起飞报告。新课从预测进入，不强制抄写长程序；每项都需解释、修改和独立编程。独立题按实际输出和贡献来源评分，指定的消息值与函数结果必须用于输出计算。
- 课程执行现场：除原跳跃课外，十二项课程显示实际消息、名字、计算、函数与分支过程。可暂停、逐条查看、退回和重放，源码区间对应真实记录；编辑失效、错误／等待与截断明确分开，观察不授分。[记录与场景契约](program-scene.md)说明范围。
- 保险库行动：三道机关，执行程序输出解锁，本地草稿与印记。
- 星港调度：条件分流、循环派送、函数供给、双消息协作四项迁移挑战。同一程序处理多批输入，展示逐批送达反馈，可更新数据重玩并保留代码、徽章与完成轮数；[输入与存档契约](dispatch.md)供维护参考。
- 星港追逐：默认20段连续路线，至少十分钟有效时间后，按真实位置追捕或抵达出口决定整局胜负。路线、路障、体力、补给与策略影响后续局势；直接控制和实际Tolang程序均可参与。暂停、后台和策略编辑不计时。六个原短实验保留逐条调试、试跑、源码反馈、独立草稿和旧档；[连续规则与保存边界](pursuit.md)和下方短实验规则分别说明。
- 编程入门：八个概念通过可编辑程序与实际执行结果观察，语言对比作为入门子页；不是完整编译器或TVM。[学习工作台](learning-guide.md)说明运行范围。
- 概念地图：入门子页按13项现有内容显示前置建议和应用方向，可运行原示例、进入引导任务或直接独立编程；没有强制解锁，不因查看而记完成。[地图与学习路径](learning-map.md)说明边界。
- 能力诊断：九个可直接选择的部分以同一程序处理变化输入，提供方向／代码框架两级提示、补学与独立任务入口；保存提交后重载仍重新执行，不将导入通过标记当成掌握证据。[诊断契约](diagnostic-design.md)说明保存与反馈。
- 十一种语言；账号登录独立于浏览器学习存档。可在进度页手动上传、读取、比较并恢复账号存档，也可下载导入文件；不在登录时自动覆盖本地。[六域存档契约](progress-saves.md)保留旧版本兼容。找回密码和全站排行榜仍未实现。

## 星港追逐代码实验的规则与存档边界

学习解释器执行受限的整数、布尔值、列表、计算、名字、条件、循环、函数、消息与联合接收，并非完整Tolang编译器或TVM。追逐把 1–3 的整数输出读作移动信号，每份计划 1–8 条；循环与函数也可生成计划。这是应用规则，不是新增Tolang指令。整段计划先运行并验证，非法输出不产生半段移动。

受控角色先动，对手再前进一格。只有受控角色的落点受路障限制，可以跨越路障；被拦住仍消耗一次行动。警察到达或超过小偷即捕获，小偷到达第 18 格即逃脱，结束后的输出不再消费。对手的自动移动不受路障影响。

`loopuff-chase-v1` 按角色保存关卡、草稿、当前提交和已通关街区。位置与动画由提交重新计算，不独立持久化。编辑使当前结果失效，通关历史保留；重玩只重置当前角色的计划，不清空旧课程、保险库或另一个角色。追逐暂不计入探索积分，既有积分规则保持不变。

亲手试跑只消费同一规则的结果，不直接颁发通关。试跑轨迹是暂态，点击“放进编辑器”才替换当前草稿。Canvas控制器负责人物姿态、脚下地面、镜头、路障、出口和小地图，不拥有独立胜负逻辑。暂停保留动画时间，编辑、换角色和导航取消旧动画；图片和图集最多等待45秒，失败后允许重试。美术母版、提示词与原生尺寸记录在 `art/chase/README.md`。

逐步调试仍先验证整份程序和全部输出，不允许错误计划产生部分移动。执行记录只显示已观察到的行动；起点显示全部输出条数，不预告追逐在哪一步结束。退回是在查看同一执行记录，不撤销已保存的通关历史；当前调试尚未走完时不能进入下一街区。源码区间与名字快照由入门运行器产生，场景原因沿用追逐规则；这些记录不冒充 Tolang 编译器指令或 TVM 执行成本。调试游标和动画保持暂态，旧 v1 存档无须迁移。

## 本轮工程核验（2026-10-26）

新增规则测试覆盖六个角色／街区组合的多解可达性、路障、结束顺序、非法输入、空草稿、版本恢复和阶段跳跃拒绝。两个变异实验分别关闭路障与改变对手步长，都被规则检查捕获；正常对照通过。

全站读取存档时增加 JSON 根类型保护，避免 `null` 导致启动报错。正常草稿与进度格式不变。

账号中继的客户端地址来源依赖部署边界。[Vercel 请求头文档](https://vercel.com/docs/headers/request-headers)说明平台覆盖 `x-forwarded-for`，且 `x-real-ip` 与它相同。因此仅从转发该头的代码不能推断当前生产存在可伪造地址漏洞。公开上游入口与多层代理的实际限流行为仍需单独验证，本轮不改账号部署。

自动测试不证明零基础学习效果。下一轮内容扩展前，应找未看过示例的玩家观察能否解释每次移动，而非只记住可通关的数字。
