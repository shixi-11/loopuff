# 银行潜入：实现契约

这是一段原创虚构编程潜入任务。入口为 `/play/heist/`，位于游乐场中；不新增主导航，也不替换原保险库实验或持续追逐。

## 玩家与程序

玩家在连续移动的横向银行走廊里取得钥匙、打开门、开启保险柜并携带物品抵达出口。巡逻者有实际位置、方向、视距和接触范围；暗处可隐蔽，体力、警戒、开锁时间与行动共同决定后续局势。练习没有倒计时，挑战有有效行动时间预算；暂停、编辑、后台和加载不计入。追逐原有至少十分钟的契约不变，本任务不替换追逐。

每800毫秒，学习运行器在当前世界快照上执行玩家的 `decide(distance, guard, facing, cover, alarm, energy, phase)`，任务追加一次调用与输出。参数为目标的有符号距离、巡逻者的有符号距离和方向、当前位置能否隐蔽、警戒、体力及目标阶段。调用必须产生一个1—6的整数信号：前进、潜行、等待／在暗处隐蔽、操作目标、后退、冲刺。这些是游戏的输入输出协议，不是Tolang内建移动命令。允许同步返回或有效的函数回复，以及不同的正确程序。

程序运行错误、未满足接收、额外输出或非法信号都会暂停，不先执行一半错误计划；修复后可从原局势继续。检查代码不改变世界，部署会在当前快照上获得新的行动。代码每次从快照重新执行，不暗中保留上次调用的语言环境。

## 世界规则

20毫秒固定步、整数毫米位置与整数资源。玩家的前进、潜行、后退和冲刺有不同速度与体力代价。巡逻者按种子产生的路线连续行走，警戒高且看见玩家时可实际追近；不瞬移或锁定间距。闭门阻挡移动与视线，在暗处等待可隐蔽；联合程序动作不把巡逻者暂停。碰到可见玩家会抓住，警戒到顶会封锁，携带物品实际进入出口区域才撤离成功。

钥匙、门和保险柜均需在实际操作范围内连续操作；移动或隐蔽中断尚未完成的操作。完成的目标保留，失误不会静默回滚已取得的进度。不同种子改变目标位置、巡逻初始局势和挑战时间；同一代码应能处理变化输入。

## 保存与集成边界

核心状态有独立版本、种子、局号、运行状态、有效时间、双方位置、资源、物品、当前动作、策略草稿、已部署策略和有限事件记录。报告为暂态；读取运行中记录后暂停，离线时间不补算。每局结果只记一次，个人记录不冒充服务器验证的排名或语言掌握。

使用独立的 `heist` 存储域；备份v3保留v1四域、v2五域读取与正常合并。恢复日记、坏数据导出、完整局势冲突预览和账号条件写入一起覆盖新域。服务器在revision检查后拒绝会遗漏已有heist的v1/v2写入。

`heist-session.js` 在切换语言和页面重挂载之间持有同一现场。它与持续追逐共用 `session-save-queue.js`：每次请求等待包含它的写入，完成微任务中的新请求不会遗失；保存失败暂停，视图通知错误显式上报而不搁置后续保存。每次新局使用独立UUID，重复种子不会覆盖历史。

画面复用已确认的人物动作素材，以实际世界坐标绘制走廊、门、保险柜、视野和隐蔽区。界面支持现场展开、有效计时、策略检查与部署、当前输入、可选提示及示例；实际游戏文本覆盖十一种语言，代码保持LTR。恢复档不会把离线时间算作行动。

## 可检查条件

合法策略在多种种子下真正完成目标和撤离；硬编码前进会受门阻挡。隐蔽、视线、接触、体力、警戒、操作中断及超时分别有可复现结果；分割时间片保持同一结果。暂停、无效代码、重载不补算移动，回放不重复颁发记录。策略样例用当前固定Tolang原生构建验证。界面另须验证真实连续运动、完整游玩、键盘／触控、十一种语言、窄屏和既有游戏／存档保持。
