# 可操作的入门与语言对照

`/guide/` 是信号台实验，不计入课程成绩。八个可选概念复用现有课程中已经核过原生语法的程序：输出、计算、名字、条件、列表循环、同步函数、回复与联合接收。代码由现有受限运行器执行，日志值驱动航标和输出列表；逐条查看使用运行器返回的源码范围。它不把日志显示成语言本身自带的角色移动能力，也不声称展示完整并发调度。

修改即清除当前报告，改回旧源码也必须重新运行。未知名字、语法位置、无输出、等待消息分别显示；已经输出后仍等待的程序同时保留日志和等待说明。重放只查看已有输出，不再次执行程序。后台、离页和销毁停止重放，日志按钮获得焦点也停止自动播放。

手机先展示编辑与运行，再展示观察窗；运行后转到结果，概念栏可横向选择。桌面保留并排的观察窗与编辑器。全局页面缩放、首页和已确认素材不变。

## 草稿与进度

实验代码保存在原课程存档的可选 `state.guideWork` 中，按概念区分；`guideSelected` 记住所选概念。报告不持久化，重载后需要重新运行。空草稿仍表示玩家确实清空过编辑器。它们不覆盖 `lessonWork`、既有草稿、成绩或完成记录。

现行v3六域备份格式支持这些可选字段，无字段的旧存档继续可读，也兼容旧四域、五域文件。导出、账号存档和恢复包含实验草稿；两端同概念源码不同会要求逐项选择。保存和恢复沿用同一写锁与恢复记录。

## 语言对照子页面

`/guide/compare/` 属于编程入门，主导航仍为首页、游乐场、编程入门。前六个概念展示固定的Tolang、Python、JavaScript、Rust示例与相同的数值输出；上方实验台可另行修改。只有Tolang在网页中执行，不对消息、回复和并发提供伪造的逐字翻译。示例和对照说明为本项目原创，没有引入第三方教程代码或素材。

十八段Python、JavaScript、Rust对照已分别在本机Python 3.12.14、Node 24.19.0、Rust 1.97.0实际运行，输出与对应课程一致。内部运行证据在 `output/guide-language-check/evidence.json`，不据此宣称这些语言的类型、调用机制或调度相同。对照依据：[Python控制流教程](https://docs.python.org/3/tutorial/controlflow.html)、[JavaScript官方指南](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide)、[Rust控制流](https://doc.rust-lang.org/book/ch03-05-control-flow.html)。

## 本轮吸收的教学方法与边界

2026-11-03核对了Exercism的[学习与练习模式](https://exercism.org/docs/building/product/unlocking-exercises)和[概念练习设计](https://exercism.org/docs/building/tracks/concept-exercises)：采用可直接选择概念、进入独立任务、提示与目标对应的思路，不复制练习题或文字。Blockly Games的[官方介绍](https://blockly.games/about?lang=en)说明从循环、条件、函数逐步过渡到文本编程；这里采用可观察结果和逐步增加概念的组织方法，没有复制它的关卡。

Grok三个调研任务已通过订阅路由派出。连续游戏子任务明确报告缺少可用联网工具，不能把命令成功退出算作玩法调查成功。报告中对 `7.log()` 的猜测未被采用，Tolang事实继续依据本项目已验证例子。产品文档核查与真实试玩、学习效果验证分开记录。
