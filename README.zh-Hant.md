## 目前程式碼

儲存庫目前包含支援數值、加法、名稱綁定和顯示的入門教學直譯器。在本機執行，不需後端、外部模型或第三方相依套件。遊戲介面和課程仍在開發；它不是完整的 Tolang 編譯器或 TVM。

## 開發

```sh
npm test
npm run build
npm run dev
```

## 語言規範

介面、課程、測驗、提示和錯誤訊息使用所選語言。簡體名稱為「环灵」，繁體名稱為「環靈」，其他語言統一使用 Loopuff。程式碼識別字和標點不翻譯。阿拉伯文由右向左排版，程式碼始終由左向右。
