## 目前程式碼

第一章已可遊玩：4 個航程學習數值、加法和名稱綁定，每關包含預測、解釋、修改和自主編寫。介面與課程支援 11 種語言。程式透過瀏覽器內的小型教學直譯器執行，無需後端或第三方依賴。它不是完整的 Tolang 編譯器或 TVM，後續章節仍在開發。

獨立程式題提供百分制測評，分別檢查程式執行、實際輸出和題目要求。可以修改後重交，不依打字速度或是否照抄範例評分。

第四關用程式輸出控制機器人的跳躍距離。執行程式，觀察落點，再修改計算，讓它抵達浮島。

## 開發

```sh
npm test
npm run build
npm run dev
```

## 語言規範

介面、課程、測驗、提示和錯誤訊息使用所選語言。簡體名稱為「环灵」，繁體名稱為「環靈」，其他語言統一使用 Loopuff。程式碼識別字和標點不翻譯。阿拉伯文由右向左排版，程式碼始終由左向右。
