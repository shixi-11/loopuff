Học lập trình và Tolang qua trò chơi.

Đọc mã, dự đoán kết quả, sửa chương trình rồi tự giải bài toán mới mà không cần mẫu.

## Mã hiện có

Kho mã hiện có trình thông dịch phục vụ học tập, hỗ trợ số, phép cộng, gán tên và hiển thị. Chạy cục bộ, không cần máy chủ, mô hình bên ngoài hay gói phụ thuộc. Giao diện trò chơi và bài học đang được phát triển. Đây không phải trình biên dịch Tolang hay TVM đầy đủ.

## Phát triển

```sh
npm test
npm run build
npm run dev
```

## Quy tắc ngôn ngữ

Giao diện, bài học, câu hỏi, gợi ý và lỗi dùng ngôn ngữ đã chọn. Tên tiếng Trung giản thể là 环灵, phồn thể là 環靈; các ngôn ngữ khác dùng Loopuff. Không dịch tên định danh hoặc dấu trong mã. Văn bản Ả Rập viết từ phải sang trái, mã luôn từ trái sang phải.
