# Loopuff

[English](README.md) · [简体中文](README.zh.md) · [繁體中文](README.zh-Hant.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Tiếng Việt](README.vi.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Русский](README.ru.md) · [Українська](README.uk.md) · [العربية](README.ar.md)

게임으로 프로그래밍과 Tolang을 배웁니다.

코드를 읽고 결과를 예측한 뒤 수정해 보세요. 마지막에는 예시 없이 새로운 문제를 해결합니다.

## 현재 코드

숫자, 덧셈, 이름 바인딩, 출력을 지원하는 학습용 인터프리터가 들어 있습니다. 백엔드, 외부 모델, 추가 패키지 없이 로컬에서 실행됩니다. 게임 화면과 과정은 개발 중이며 완전한 Tolang 컴파일러나 TVM은 아닙니다.

## 개발

```sh
npm test
npm run build
npm run dev
```

## 언어 규칙

화면, 수업, 문제, 힌트, 오류는 선택한 언어로 표시합니다. 중국어 간체에서는 环灵, 번체에서는 環靈, 다른 언어에서는 Loopuff를 사용합니다. 코드 식별자와 기호는 번역하지 않습니다. 아랍어는 오른쪽에서 왼쪽으로, 코드는 왼쪽에서 오른쪽으로 표시합니다.
