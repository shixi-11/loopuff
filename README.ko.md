## 현재 코드

1장의 미션 3개를 플레이할 수 있습니다. 값, 덧셈, 이름 바인딩을 배우며 예상, 설명, 수정, 직접 코딩을 연습합니다. 화면과 수업은 11개 언어를 지원합니다. 작은 학습용 인터프리터가 브라우저 안에서 작동하며 백엔드나 외부 패키지가 필요하지 않습니다. 전체 Tolang 컴파일러나 TVM은 아니며, 다음 장은 개발 중입니다.

## 개발

```sh
npm test
npm run build
npm run dev
```

## 언어 규칙

화면, 수업, 문제, 힌트, 오류는 선택한 언어로 표시합니다. 중국어 간체에서는 环灵, 번체에서는 環靈, 다른 언어에서는 Loopuff를 사용합니다. 코드 식별자와 기호는 번역하지 않습니다. 아랍어는 오른쪽에서 왼쪽으로, 코드는 왼쪽에서 오른쪽으로 표시합니다.
