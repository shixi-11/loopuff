# 星港追逐美术与运行资产

本组用于侧视二维追逐关卡。警察与小偷采用成人真人比例、可辨认的脸和职业服装，场景是蓝调黄昏的星港街区。人物不是圆点、几何占位符或仅用于展示的插图，运行时逐姿态绘制并参与移动、跳跃、受阻与结束动作。

本轮使用内置 image_gen。该入口只提供提示词，不能锁定 size / quality 参数；提示词请求最高原生质量与原生4K优先，实际尺寸以上表为准。没有升格、放大、拉伸或转4K JPG。透明PNG原件完整保留；`chase-*-idle.png` 是站立帧的原尺寸运行裁片，未缩放。

`chase-sprites.json` 登记每个姿态的实际原图矩形。生成图的排布并非精确等分网格，所以运行时消费登记矩形，不机械等分裁断手脚；同一角色所有姿态使用同一像素缩放比例，不把每个姿态强拉成同样宽高。角色脚底与背景原图70%高度处的行走线对齐。透明边缘、脸、手、脚与姿态必须同时在原图和真实游戏显示中检查。

## 提示词与制作方向（中文整理）

**警察：** 真实人体比例的成年男性警察，海军蓝警帽、浅蓝短袖制服、深蓝长裤与黑鞋，无武器、文字和品牌；统一右向侧面、脸与服装一致。透明4列2行，8个完整姿态：站立、右腿前跑、左膝过渡、左腿前跑、右膝过渡、腾空跨越、受阻平衡、向前伸出双手抓捕。皮肤、织物和金属有不同质感；所有可见手指、手掌、帽子和鞋都完整收入画内，保持清楚净边。

**小偷：** 真实人体比例的成年男性，深灰连帽外套、棕色帆布斜挎包、炭灰长裤、浅灰鞋，面孔可见，无武器、文字和品牌；右向侧面，统一身份、头部与体型。相同透明4列2行布局，前7姿态对应站立、4段跑步、腾空和受阻，第8姿态为逃脱后的举手动作。跑步须有不同腿部支撑与手臂反向摆动，不把同一张站姿平移冒充动画。

**街区：** 蓝调黄昏的星港城市，正侧视游戏镜头；前景连续平整人行道，中景砖石建筑、门窗、桥梁和琥珀路灯，远景港口起重机与飞船。深靛蓝、蓝灰与少量暖金光；保留清楚可跑动的空地，不画入人物、前景障碍、UI、网格或文字，供真实游戏角色与机关独立消费。

**道具：** 真透明独立侧视金属路障与开放的星港出口。冷灰蓝金属、淡奶油和琥珀反光条，出口有小型暖光灯；结构、支撑脚与轮廓完整，没有文字、标志、烤入底色或网格。

## 验证边界

静态复核包含完整轮廓、深浅底、脸手局部、Alpha与实际运行缩放；运行复核包含角色落地、跳跃、镜头追随和出口完整性。自动检查约束图集帧数、矩形和动画端点，也检查真实绘制链与取消路径；这些不等于用户已经认可美术或玩家已经证明游戏好玩。
