读懂代码，预测结果，修改程序，再独立解决新的问题。

## 当前代码

第一章已可游玩：3 个航程学习数值、加法和名字绑定，每关包含预测、解释、修改和自主编程。界面与课程支持 11 种语言。程序在浏览器内通过小型教学解释器运行，无需后端或第三方依赖。它不是完整的 Tolang 编译器或 TVM，后续章节仍在开发。

## 开发

```sh
npm test
npm run build
npm run dev
```

## 语言规范

界面、课程、考题、提示和错误信息使用所选语言。简体名为“环灵”，繁体名为“環靈”，其他语言统一使用 Loopuff。代码标识符和标点不翻译。阿拉伯文从右向左排版，代码始终从左向右。
