[金庫ミッション](https://shixilin.com/games/loopuff/ja/play/vault/)では、3つの仕掛けに挑戦できます。計算結果でロックを開け、名前を使い、信号を順番に送ります。新しいヒントで再挑戦でき、コードと3つのスタンプは保存されます。

[宇宙港の配送指令](https://shixilin.com/games/loopuff/ja/play/dispatch/): 条件分岐、ループ、関数、連携するメッセージで貨物を振り分けよう。新しいラウンドでは新しい配送データが届きます。

## 現在のコード

13のミッションで、プログラミングの基礎から、Tolangの条件分岐、ループ、関数と返信、さらにメッセージと結合受信まで学びます。各ミッションには、予測、説明、修正、自力で取り組む課題があり、最初の4つには飛行練習も残されています。コースとインターフェースは11言語に対応しています。プログラムは、完全なTolangコンパイラやTVMではなく、機能や実行範囲を制限した学習用インタープリターでローカルに実行されます。自力で取り組む課題では、実際の出力と、指定された概念がその出力の生成に使われているかを確認します。タイピングの速さは成績に影響しません。

独立課題では実行、出力、条件の達成を100点満点で採点します。修正して再提出でき、入力速度や見本との一致は得点に影響しません。

4つ目のミッションでは、プログラムの出力が飛行機の跳ぶ距離になります。実行して着地点を見ながら、計算を変えて浮島を目指します。

## 言語の規則

画面、教材、設問、ヒント、エラーは選択した言語で表示します。中国語簡体字では「环灵」、繁体字では「環靈」、その他の言語では Loopuff を使います。コードの識別子や記号は翻訳しません。アラビア語は右から左、コードは左から右に表示します。
