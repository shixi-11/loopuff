ゲームを通してプログラミングと Tolang を学ぶ。

コードを読み、結果を予測し、書き換え、最後はひな形なしで新しい課題に挑戦します。

[shixilin.com/games/loopuff](https://shixilin.com/games/loopuff/ja/)

## 現在のコード

第1章の3ミッションをプレイできます。数値、足し算、名前の束縛を、予想・説明・変更・自分で書く課題を通して学びます。画面と教材は11言語に対応。小さな学習用インタープリターがブラウザー内で動き、バックエンドや外部パッケージは不要です。完全な Tolang コンパイラーや TVM ではありません。続く章は開発中です。

## 開発

```sh
npm test
npm run build
npm run dev
```

## 言語の規則

画面、教材、設問、ヒント、エラーは選択した言語で表示します。中国語簡体字では「环灵」、繁体字では「環靈」、その他の言語では Loopuff を使います。コードの識別子や記号は翻訳しません。アラビア語は右から左、コードは左から右に表示します。
