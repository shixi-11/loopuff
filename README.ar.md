تعلّم البرمجة ولغة Tolang من خلال اللعب.

اقرأ الشيفرة، وتوقّع نتيجتها، وعدّلها، ثم حل مسائل جديدة دون قالب جاهز.

## الشيفرة الحالية

يحتوي المستودع حاليًا على مفسّر تعليمي صغير للأعداد والجمع وربط الأسماء وعرض النتائج. يعمل محليًا دون خادم أو نماذج خارجية أو حزم إضافية. واجهة اللعبة والدروس قيد التطوير. وهو ليس مترجم Tolang الكامل ولا TVM.

## التطوير

```sh
npm test
npm run build
npm run dev
```

## قواعد اللغات

تظهر الواجهة والدروس والأسئلة والتلميحات والأخطاء باللغة المختارة. الاسمان الصينيان هما 环灵 و環靈، وتستخدم اللغات الأخرى اسم Loopuff. لا تُترجم معرّفات الشيفرة أو رموزها. يُعرض النص العربي من اليمين إلى اليسار، وتبقى الشيفرة من اليسار إلى اليمين.
